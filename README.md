# 🧾 ATS Job Posting + Application Preview

An interactive and responsive Applicant Tracking System (ATS) design prototype built using **HTML**, **Tailwind CSS**, and **JavaScript**. This project includes both **Job Posting (Recruiter Side)** and **Application Preview (Candidate Side)** functionalities with full light/dark mode support 🌗.

---

## 🎯 Features

- 🔄 **Light/Dark Mode Toggle**
- 🧑‍💼 **Job Posting Form** with:
  - Job Title, Type, Location
  - Salary Range, Experience Level
  - Rich Description & Skills Tag Input
- 👀 **Live Preview for Candidates** with:
  - Clean layout and info hierarchy
  - Attractive “Apply Now” CTA
- 📱 **Fully Responsive** on mobile, tablet, and desktop
- 🎨 **Interactive Animations** and transitions
- ✅ **Client-side Validation** for form completeness

---

## 🧑‍💼 User Personas

### 👤 Recruiter
- Goal: Quickly post a job with clarity
- Needs: Smart templates, reusable input fields, easy preview

### 👤 Job Seeker
- Goal: View jobs that are clear and enticing
- Needs: Transparent info, perks, clean UI, responsive layout
